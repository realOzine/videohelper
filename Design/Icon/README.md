# VideoHelper 项目图标

`videohelper-icon.svg` 是项目图标：画面、台词、声音三条轨道，红色播放头落在三路同时命中的那一刻。设计过程、备选方案和完整规范见 `../Kite/`（`GUIDELINES.md`）。

## 文件

| 文件 | 用途 |
|---|---|
| `videohelper-icon.svg` | 主图标，浅底 |
| `videohelper-icon-reversed.svg` | 深底（轨道米纸色，形状内缩 1 单位） |
| `videohelper-icon-black.svg` / `-white.svg` / `-red.svg` | 单色；红底或杂乱背景用白色 |
| `videohelper-icon-small.svg` / `-small-reversed.svg` | 24 px 及以下的小尺寸版 |
| `videohelper-icon-tile.svg` | 墨黑圆角底的小尺寸版，即 favicon |
| `videohelper-app-icon.svg` | App 图标（墨黑底） |
| `png/` | 主图标 16–1024 px（16、24 px 来自小尺寸版），反白版和 App 图标 256/512/1024 px，透明底 |
| `web/` | favicon.ico/svg、favicon 16/32/48、apple-touch-icon、PWA 192/512/maskable、`site.webmanifest`、`head-snippet.html` |

## 颜色

墨黑 `#0f0e15`、米纸 `#f3ede2`、红 `#f43d3f`。红色只用于播放头。

## 最小尺寸与留白

主图标 ≥ 32 px，更小换小尺寸版；四周留白 ≥ 一条轨道的高度（图标高度的 14%）。
